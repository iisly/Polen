# Polen - 꽃가루 알레르기 케어
기상청_꽃가루농도위험지수 조회서비스(3.0) 기반 계절성 알레르기 및 비염 환자 맞춤 케어 웹서비스

## 주요 기능

1. **실시간 꽃가루농도위험지수 대시보드**
   - 오늘, 내일, 모레 위험 단계(낮음 `0` / 보통 `1` / 높음 `2` / 매우높음 `3`)
   - 최고 위험 단계에 맞춰 환자 행동 요령 제공
2. **3대 꽃가루 수종별 정밀 예보**
   - **참나무**: 3월 ~ 6월 (봄철 호흡기 알레르기 주범)
   - **소나무**: 3월 ~ 6월 (봄철 노란 송홧가루, 기도 점막 자극)
   - **잡초류(돼지풀·환삼덩굴·쑥)**: 8월 ~ 10월 (가을철 알레르기 비염 및 천식 유발)
3. **전국 17개 시·도 및 정밀 GPS 위치 기반 조회**
   - 200여 개 시·군·구 좌표 기반 최근접 시·도 매칭
4. **항히스타민제 복용 가이드**
   - 대표 2세대 항히스타민제 성분별 특징 및 복용 팁
5. **대한민국 연간 12개월 꽃가루 달력**
   - 월별 수목류 및 초본류 비산 타임라인 안내
