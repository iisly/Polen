## 주요 기능

1. **실시간 꽃가루농도위험지수 대시보드**
   - 오늘, 내일, 모레 위험 단계(낮음 `0` / 보통 `1` / 높음 `2` / 매우높음 `3`)
   - 최고 위험 단계에 맞춰 환자 행동 요령 제공
2. **3대 꽃가루 수종별 정밀 예보**
   - **참나무**: 4월 ~ 6월 (봄철 호흡기 알레르기 주범)
   - **소나무**: 4월 ~ 6월 (봄철 노란 송홧가루, 기도 점막 자극)
   - **잡초류(돼지풀·환삼덩굴·쑥)**: 8월 ~ 10월 (가을철 알레르기 비염 및 천식 유발)
3. **전국 17개 시·도 및 GPS 위치 기반 조회**
   - 브라우저 위치 서비스(GPS)를 이용한 현재 위치 가장 가까운 시·도 기준으로 조회
4. **항히스타민제 복용 가이드**
   - 알레르기 인들의 필수 아이템 항히스타민제 안내
5. **대한민국 연간 12개월 꽃가루 달력**
   - 봄철 수목류와 가을철 초본류의 연간 발생 타임라인 안내
