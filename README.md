## 📌 주요 기능

1. **실시간 종합 꽃가루 위험도 대시보드**
   - 오늘 위험 단계(낮음 `0` / 보통 `1` / 높음 `2` / 매우높음 `3`) 시각화 게이지
   - 최고 위험 수종 자동 탐지 및 환자 핵심 한 줄 권고 요령 제공
2. **3대 꽃가루 수종별 정밀 예보**
   - **참나무**: 4월 ~ 6월 (봄철 호흡기 알레르기 주범)
   - **소나무**: 4월 ~ 6월 (봄철 노란 송홧가루, 기도 점막 자극)
   - **잡초류(돼지풀·환삼덩굴·쑥)**: 8월 ~ 10월 (가을철 알레르기 비염 및 천식 유발)
   - 오늘, 내일, 모레 단계별 예보 제공
3. **전국 17개 시·도 및 GPS 위치 기반 조회**
   - 브라우저 위치 서비스(GPS)를 이용한 현재 위치 가장 가까운 시·도 자동 매칭
4. **질환별 맞춤 예방 가이드**
   - **알레르기 비염**: 비강 세척(생리식염수), KF94 마스크, 항히스타민 복용 시점
   - **기관지 천식**: 야외 유산소 운동 중단 기준, 응급 흡입기 지참 요령
   - **알레르기 결막염**: 눈 비비기 금지, 인공눈물 세척, 보호안경 착용
   - **아토피/피부염**: 외출복 관리, 귀가 후 샤워, 보습 가이드
5. **외출 전 안심 체크리스트**
   - 외출 전 환자가 챙겨야 할 필수 항목 인터랙티브 체크박스 및 달성률 게이지
6. **대한민국 연간 12개월 꽃가루 달력**
   - 봄철 수목류와 가을철 초본류의 연간 발생 타임라인 및 현재 월 표시
7. **하이브리드 공공데이터 연동 & 시뮬레이션 모드**
   - API 키가 없거나 비시즌/점검 중에도 실감나는 시뮬레이션 데이터를 제공
   - 웹 UI에서 공공데이터포털 일반 인증키를 직접 입력하여 즉시 실시간 데이터 연동 가능 (`localStorage` 저장 지원)

## 🚀 빠른 시작

### 1. 개발 서버 실행
```bash
npm run dev
```
브라우저에서 [http://localhost:3000](http://localhost:3000) 접속

### 2. 공공데이터포털 API 연동 (선택사항)
1. [공공데이터포털(data.go.kr)](https://www.data.go.kr/data/15085288/openapi.do) 접속
2. `기상청_꽃가루농도위험지수 조회서비스(3.0)` 검색 후 **활용신청** (즉시 승인)
3. 웹페이지 우측 상단의 **[API 인증키 설정]** 버튼을 눌러 발급된 인증키 입력
   *(또는 `.env.local` 파일 생성 후 `KMA_POLLEN_API_KEY=발급키` 저장)*
